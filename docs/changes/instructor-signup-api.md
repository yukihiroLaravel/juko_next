# 講師の新規登録（仮登録・認証コード入力）を API につなぐ

## 目的

講師の仮登録の画面と認証コード入力の画面を実際の API につなぎ、仮登録から本登録を経て、講師ログインの画面へ進めるようにする。

## 背景

JKA-1821。JKA-1820 で作った2画面は、登録を押すと入力値を console.log に出すだけで、仮登録の完了の案内も、送信の成否によらず出していた。

次の点は、この変更では決めない。

- 認証メールに書かれる URL は受講生と講師で共通（`{ALLOW_ORIGIN}/verification/{token}`）で、講師側の認証コード入力の画面に届かない。メールの token を手で `/instructor/verification/{token}` に貼って確かめる

次の点は、講師と相談して決めた。

- 422 で返る文言のうち、メールアドレスの重複は日本語に置き換える。ほかの項目は、画面の入力の検証がバックエンドと同じか厳しいので、画面から送った場合は返らない

## 変更する振る舞い

| 対象                                | 現在                   | 変更後                                                                                                                           |
| ----------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `AC-ISIGNUP-002` 仮登録の完了の案内 | 登録を押せば出す       | 仮登録に成功したときだけ出す                                                                                                     |
| `AC-ISIGNUP-004` 本登録の実行       | console.log に出すだけ | 本登録の API を送り、成功したら講師ログインの画面へ移る                                                                          |
| 入力の項目ごとの誤り（新設）        | —                      | サーバーが項目ごとに返した誤りを、該当する入力欄の下に出す。講師名・姓・名・メールアドレス（重複を含む）、認証コード・パスワード |
| 送信の失敗（新設）                  | 出す場所だけある       | 決めた日本語の文言をフォームの上の枠に出す。サーバーの message は出さない                                                        |
| 仮登録からやり直す案内（新設）      | —                      | 認証コードの誤りが上限を超えたとき、有効期限が切れたとき、URL の仮登録が見つからないときは、仮登録の画面へのリンクを出す         |

| 講師ログインの画面（新設）          | —                      | 本登録のあとに移ってきたときだけ、登録が済んだことを伝える案内を出す                                                             |
| 前提にする API の振る舞い           | —                      | AC-ACCOUNT-001〜019                                                                                                              |

画面の受け入れ基準の ID は、`AC-ISIGNUP-007` から新しく振る。

## 変更する範囲

| 範囲               | 内容                                                                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 画面               | 仮登録の画面・認証コード入力の画面の送信中と失敗の表示、仮登録からやり直すリンク。講師ログインの画面に、登録が済んだことを伝える案内を置く          |
| データの取得と送信 | 仮登録と本登録の送信のフックを新しく作る。CSRF の Cookie を取ってから送る。利用者向けの文言と、仮登録からやり直す必要があるかどうかはフックで決める |
| 入力の検証         | 変えない                                                                                                                                            |
| 共通の部品         | なし。既存の部品だけを使う。画面のパスの定義に講師ログインを足す                                                                                    |

## 前提にする API

- 講師の仮登録 `POST /api/v1/instructors`（認証不要）。バックエンドにある
- 認証コードの検証と本登録 `POST /api/v1/instructors/verification/{token}`（認証不要）。バックエンドにある
- CSRF の Cookie `GET /sanctum/csrf-cookie`。バックエンドにある

失敗のときに返る message は英語の固定文言である。画面には出さず、判定にだけ使う。

## 画面に出す文言

| 画面           | 場面                                              | 文言                                                                                                               | 仮登録からやり直すリンク |
| -------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------ |
| 仮登録         | 認証コードか token を作れなかった、そのほかの失敗 | 仮登録に失敗しました                                                                                               | なし                     |
| 仮登録         | メールアドレスがすでに講師として登録されている    | このメールアドレスはすでに登録されています（メールアドレスの欄の下に出す）                                         | なし                     |
| 認証コード入力 | 認証コードが一致しない                            | 認証コードが正しくありません。メールに記載の認証コードを確かめて、もう一度入力してください                         | なし                     |
| 認証コード入力 | 誤りが上限を超えた                                | 認証コードの誤りが上限を超えたため、この仮登録は無効になりました。お手数ですが、仮登録からやり直してください       | あり                     |
| 認証コード入力 | 有効期限が切れた                                  | 認証コードの有効期限（60分）が切れたため、この仮登録は無効になりました。お手数ですが、仮登録からやり直してください | あり                     |
| 認証コード入力 | 仮登録が見つからない、URL の token が誤っている   | この URL の仮登録が見つかりません。無効になったか、URL が誤っている可能性があります。仮登録からやり直してください  | あり                     |
| 認証コード入力 | そのほかの失敗                                    | 本登録に失敗しました                                                                                               | なし                     |
| 両方           | 通信と関係のない予期しない失敗                    | 予期しないエラーが発生しました                                                                                     | なし                     |
| 講師ログイン   | 本登録のあとに移ってきたとき                      | 本登録が完了しました。登録したメールアドレスとパスワードでログインしてください。                                   | —                        |

リンクの文言は「仮登録からやり直す」とし、仮登録の画面へ移る。
