# 講師側 受講期限一括変更

## 目的と利用者

講師が講座一覧で選択した講座の受講期限をまとめて変更する画面である。

## パス

`/instructor/courses/deadline`

## 受け入れ基準

1. `AC-ICDEAD-001` 選択された講座がないとき、システムは履歴を置き換えて講座一覧へ戻し、選択があるときは対象件数を表示しなければならない。
2. `AC-ICDEAD-002` システムは期限なし・日付指定・日数指定を受け付け、日付指定と日数指定の未入力を促さなければならない。正しい日付・日数を選択した時点で未入力エラーを解消しなければならない。更新の前には対象件数と変更内容を示して確認を求め、キャンセルまたはEscで閉じられなければならない。
3. `AC-ICDEAD-003` システムは削除の前に確認を求め、対象件数と設定をなくすことを示し、確認後に操作と対象講座のみを記録して講座一覧へ戻らなければならない。

## 対象外

- API連携と実際の一括更新
- レイアウトや色などの見た目の完全一致
