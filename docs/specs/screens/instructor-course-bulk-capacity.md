# 講師側 講座定員一括変更

## 目的と利用者

講師が講座一覧で選択した講座の定員をまとめて変更する画面である。

## パス

`/instructor/courses/capacity`

## 受け入れ基準

1. `AC-ICCAP-001` 選択された講座がないとき、システムは講座一覧へ戻し、選択があるときは対象件数を表示しなければならない。
2. `AC-ICCAP-002` システムは定員として1以上の整数または空欄を受け付け、0や小数は入力を促さなければならない。最大値は設けない。更新の前には確認を求めなければならない。
3. `AC-ICCAP-003` システムは削除の前に確認を求め、確認後に処理内容を記録して講座一覧へ戻らなければならない。

## 対象外

- API連携と実際の一括更新
- レイアウトや色などの見た目の完全一致
