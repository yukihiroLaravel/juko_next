# 状態と useEffect

## 状態を最小にする

- props や他の状態から計算できる値を状態にしない。描画の中で計算する
- 同じ情報を2つの状態で持たない。片方の更新を忘れると食い違う
- サーバーから取った値を useState に写さない。SWR の値をそのまま使う。編集用の下書きが要るときだけ、初期値として受け取る

```tsx
// 避ける
const [fullName, setFullName] = useState('');
useEffect(() => setFullName(`${last} ${first}`), [last, first]);

// こうする
const fullName = `${last} ${first}`;
```

## useEffect を使わない書き方

useEffect は外部の仕組み（ブラウザの API・タイマー・購読）と同期するためのものである。次の用途では使わない。

| 用途                               | 代わりに                                     |
| ---------------------------------- | -------------------------------------------- |
| props から値を計算する             | 描画の中で計算する                           |
| 利用者の操作に応じて何かをする     | イベントの処理の中で行う                     |
| props が変わったら状態を初期化する | 親から `key` を変えて渡す                    |
| データを取得する                   | SWR のフックを使う                           |
| 親に変化を知らせる                 | 状態を変える箇所で、同時にコールバックを呼ぶ |

## 状態の置き場

- 状態は、それを使う部品のうち最も近い共通の親に置く
- 離れた部品で共有するサーバーの値は、SWR のキャッシュで共有する。Context に写さない
- Context は、テーマやログイン中の利用者のように、広い範囲で読み、まれにしか変わらない値に使う

## 更新

- 前の値に基づく更新は関数で渡す（`setCount((prev) => prev + 1)`）
- オブジェクトと配列は書き換えずに新しく作る
