# 描画の性能

## React Compiler

- このリポジトリは React Compiler が有効である。描画の結果とコールバックは自動でメモ化される
- 値の再計算を避けるためだけの `useMemo`・`useCallback`・`memo` を新たに書かない
- React Compiler は React のルールを守ったコードでしか効かない。描画の中で props や状態を書き換えない。描画の中で外部の値を読み書きしない

## リスト

- `key` には変わらない ID を使う。配列の添字を使うのは、並びが変わらず、要素に状態がないときだけにする
- 長いリスト（数百件）はページ分けか仮想化を検討する。まずページ分けを使う

## 読み込み

- 画面の初めに要らない重い部品（エディタ・グラフ）は `next/dynamic` で遅らせて読み込む
- 画像は `next/image` を使う。外部の画像の置き場は `next.config.ts` の `images` に足す
- 同じデータを複数の部品で取るときは、同じキーの SWR のフックを呼ぶ。キャッシュが1つにまとまる

## 避けること

- 計測せずに最適化する。遅いと感じたら React DevTools の Profiler で原因を確かめてから直す
