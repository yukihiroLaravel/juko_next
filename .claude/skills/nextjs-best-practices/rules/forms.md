# フォーム（React Hook Form と zod）

## スキーマ

- 入力の検証は zod のスキーマに書き、`zodResolver` で React Hook Form につなぐ
- フォームの値の型はスキーマから `z.infer` で作る。型を別に手で書かない
- エラーの文言はスキーマに日本語で書く。何を直せばよいかが分かる文にする
- 複数の項目にまたがる検証（確認用のパスワード）は `refine` か `superRefine` で書き、`path` でどの項目に出すかを決める

## 入力の部品

- 各入力に `<Label htmlFor>` を付け、`id` と対応させる
- 誤りのある入力には `aria-invalid` を付け、文言をその入力の近くに出す
- 数値や日付は、スキーマで型を変換する（`z.coerce`）か、送信の前に変換する。表示用の文字列のまま送らない

## 送信

- `form.handleSubmit` で包み、検証を通った値だけを送信のフックに渡す
- サーバーが返した誤りは `form.setError` で該当の項目に出す。項目に対応しない誤りは `root` に出す
- 送信中はボタンを押せなくする
- 成功したあとに入力を残すか消すかを決める。編集のフォームは送信した値で `reset` する

## 避けること

- 入力のたびに useState へ値を写す。React Hook Form の値を使う
- 同じ検証をスキーマと部品の両方に書く
