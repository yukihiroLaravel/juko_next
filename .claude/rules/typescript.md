# TypeScript 全般

- `any` を使わない。応答の型が分からないときは `unknown` で受けて絞り込む
- React Compiler が有効である。値の再計算を避けるためだけの `useMemo`・`useCallback` を新しく書かない
- 型や前提条件で起こりえない分岐を書かない
- 依存を足すときは、プランの「承認の前に決めてほしいこと」に書いて承認を取る

## デッドコードは消す

呼び出し元のない部品・フック・関数・型は削除する。使わなくなったコードをコメントにして残さない。

## コメント

- コメントには、名前と型から読めないことだけを書く。なぜその書き方にしたかや、null と空配列のように値の意味が分かれるときの区別である
- 処理を言い直すだけのコメントを書かない
